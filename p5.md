# P5 Hiša: prebudi Luno

## Uvod @unplugged

Ročici A in B pritisni v zaporedju A–B–A. Ko je koda pravilna, pripravi odziv Hiše in pošlji MOON Luni.

## 1. Dogodek

Dodaj dogodek ``||zacarana:ko postaja zazna rešitev||``.

```blocks
zacarana.koJeUgankaResena(function () {
})
```

## 2. Znak Hiše

Dodaj svoj 5×5 simbol hiše ali okna.

```blocks
zacarana.pokaziSimbol(images.createImage(`
    . . # . .
    . # # # .
    # # # # #
    # . # . #
    # # # # #
`))
```

## 3. Osvetljena okna

Dodaj zmagovalni zvok in čarobni učinek. Učinek prižge jantarna okna.

```blocks
zacarana.zaigrajZvok(CarobniZvok.Zmagovalni)
zacarana.izvediCarobniUcinek()
```

## 4. Prebudi Luno

Dodaj blok za naslednjo postajo. Hiša bo trikrat oddala MOON.

```blocks
zacarana.prebudiNaslednjoPostajo()
```

## 5. Preizkus

Prenesi program in pritisni A–B–A. Napačen pritisk začne zaporedje znova. Pred skupno igro pošlji RESET.

```template
zacarana.zazeniPostajo(Postaja.P5)
```
