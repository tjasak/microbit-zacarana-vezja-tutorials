# P1 Grobek: prebudi Robomonstra

## Uvod @unplugged

S svetilko prebudi skrivnostni grob. Ko micro:bit zazna dovolj svetlobe, mu določi simbol, zvok in učinek ter pošlji iskro Robomonstri.

## 1. Dogodek

Dodaj dogodek ``||zacarana:ko postaja zazna rešitev||``. Vsi naslednji bloki sodijo vanj.

```blocks
zacarana.koJeUgankaResena(function () {
})
```

## 2. Tvoj simbol

V dogodek dodaj ``||zacarana:pokaži moj simbol||`` in nariši svojo lobanjo ali duha.

```blocks
zacarana.pokaziSimbol(images.createImage(`
    . # # # .
    # . # . #
    # # # # #
    . # . # .
    . # # # .
`))
```

## 3. Zvok in neon

Dodaj skrivnostni zvok, nato čarobni učinek postaje. Motor bo varno upravljal neon na P0.

```blocks
zacarana.zaigrajZvok(CarobniZvok.Skrivnostni)
zacarana.izvediCarobniUcinek()
```

## 4. Naslednja postaja

Na konec dodaj ``||zacarana:prebudi naslednjo postajo||``. Grob bo trikrat poslal START.

```blocks
zacarana.prebudiNaslednjoPostajo()
```

## 5. Preizkus

Prenesi program. Grob naj bo ob zagonu temen, nato posveti s pripravljeno svetilko v zgornjo vrstico micro:bita. Pred skupno igro naj mentor pošlje RESET.

```template
zacarana.zazeniPostajo(Postaja.P1)
```
