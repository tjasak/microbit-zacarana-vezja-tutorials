# Začarana vezja

Slovenski MakeCode bloki in vodeni projekti za šest postaj delavnice »Začarana vezja: ko duhovi oživijo«.

Izberi tutorial: [P1 Grobek](p1), [P2 Robomonster](p2), [P3 Duhec](p3), [P4 Kotel](p4), [P5 Hiša](p5) ali [P6 Luna](p6).

Produkcijski firmware, identifikatorji naprav in interni zapiski niso del tega javnega učnega paketa.
