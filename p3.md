# P3 Duhec: prebudi Kotel

## Uvod @unplugged

Spečemu Duhcu glasno reci »BU«. Po treh glasnih meritvah se zbudi, ti pa določiš njegov odziv in pošlješ STAR Kotlu.

## 1. Dogodek

Dodaj dogodek ``||zacarana:ko postaja zazna rešitev||``.

```blocks
zacarana.koJeUgankaResena(function () {
})
```

## 2. Obraz Duhca

Dodaj svoj 5×5 simbol duha.

```blocks
zacarana.pokaziSimbol(images.createImage(`
    . # # # .
    # . # . #
    # # # # #
    # . # . #
    # . # . #
`))
```

## 3. Smeh in luč

Dodaj smeh Duhca in čarobni učinek. Učinek varno prižge njegovo luč na P0.

```blocks
zacarana.zaigrajZvok(CarobniZvok.SmehDuhca)
zacarana.izvediCarobniUcinek()
```

## 4. Prebudi Kotel

Dodaj blok za naslednjo postajo. Duhec bo trikrat oddal STAR.

```blocks
zacarana.prebudiNaslednjoPostajo()
```

## 5. Preizkus

Prenesi program in trikrat zapored glasno reci »BU«. Gumb A je mentorska rezerva. Pred skupno igro pošlji RESET.

```template
zacarana.zazeniPostajo(Postaja.P3)
```
